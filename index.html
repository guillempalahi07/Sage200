1. Introducció

Un Sistema de Gestió Empresarial (SGE) és una aplicació informàtica que permet planificar, organitzar i controlar de manera integrada els processos i recursos d'una empresa (finances, vendes, compres, magatzem, RRHH...).

Es classifiquen en tres grans tipus:

ERP

Gestiona els processos interns de l'empresa.

CRM

Centrat en la relació amb els clients.

BI

Anàlisi de dades per a la presa de decisions.

Hem escollit Sage 200, un ERP modular desenvolupat per Sage Group, ampliable amb mòduls opcionals de CRM i BI.

2. Informació general del sistema

Desenvolupador: Sage Group plc.

Llenguatge de programació: .NET (C#)

Base de dades: Microsoft SQL Server

Plataformes: Windows (client d'escriptori i servidor), accés web des de qualsevol navegador

Arquitectura: Client-servidor, amb versió web/cloud basada en arquitectura de serveis
